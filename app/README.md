# Portfolio dashboard

This is the production-buildable static dashboard for the completed conditional
MRT-area analysis. It presents the 146-area proximity and accessibility screens,
bounded competition evidence, illustrative common finance cases, final
competition-uncertainty gate and due-diligence boundary.

## Run locally

```sh
cd app
npm install
npm run dev
```

Open the local URL printed by Vite. Create a production build with
`npm run build`.
