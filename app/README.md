# Portfolio dashboard

This is the production-buildable static dashboard for the completed conditional
MRT-area analysis. It presents the 146-area nearby-population and travel-access
screens, bounded competitor evidence, the conditional shortlist and a later
15/20/25-minute travel-time check. Common finance assumptions remain in the
technical outputs but are not used to rank areas.

## Run locally

```sh
cd app
npm install
npm run dev
```

Open the local URL printed by Vite. Create a production build with
`npm run build`.

The later `travel-time-sensitivity.json` is a small public summary of the
[15/20/25-minute audit](../reports/analysis/2026-09-28/travel-time-sensitivity/travel-time-sensitivity.md).
It holds the original 36 areas fixed when comparing ranks. The candidate screen
changes slightly at 15 and 25 minutes; Macpherson enters those alternative lists
without comparable competitor evidence, so their full rankings are not claimed.
The dashboard presents Serangoon as dependent on the 25-minute assumption while
preserving the original published shortlist and results.

`final-analysis.json` is generated by the final-decision command. It excludes
branch addresses, postcodes, operator URLs, credentials and private route caches.
Release checksums and QA results are under
`reports/analysis/2026-09-18/final_decision/`.
