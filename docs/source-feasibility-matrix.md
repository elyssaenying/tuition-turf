## Competitor discovery and validation protocol

The protocol is deliberately asymmetric: broad sources discover candidates; stronger evidence validates them.

1. Freeze `analysis_cutoff`, the P1–S4 mathematics inclusion rule, aliases, and the 30-day dynamic-source window before looking at comparison results.
2. Generate a broad candidate list from S010 by Secondary Math/E-Math/A-Math, Primary Math and geography/MRT; supplement with systematic web/map searches using the same query templates for every planning area. Record the query, date, result count and page coverage even when no result is found.
3. Resolve candidates to `education_brands` and physical `education_branches`. Normalise but retain public names, addresses, units and postal codes. ACRA S011 may corroborate legal identity/status only; it cannot validate a branch.
4. Require branch-specific operator evidence for `confirmed`: a current official locations/centre page plus a current subject/level or timetable page showing mathematics and at least one P1–P6 or S1–S4 level at that location. S5 is outside scope. Generic brand-wide claims, map pins and directory categories remain `possible`.
5. Validate operating status from the operator page and a second current public signal where available. Preserve conflicts, closures and relocations; link old/new branches and count only the operating site at the cutoff.
6. Geocode each address with candidates and match quality. Deduplicate only the same operator at the same physical teaching location; two operators in one building remain two branches.
7. Recheck **100%** of branches inside shortlisted catchments and every `possible` branch capable of changing a Pareto result. Before claiming national coverage, audit directory coverage with a fixed planning-area sample and report discovery-channel yield/overlap; the sample size is frozen after the initial inventory size is known, not chosen from results.
8. Publish confirmed counts as the primary competition measure, confirmed plus all possible as the uncertainty upper-bound case, exclusions and coverage flags. Keep distance bands, level overlap, per-1,000 rates and any complex decay/overlap formulation descriptive or secondary. Never translate branch counts into seats, market share or success.

## Premises-status evidence rule

| Status | Minimum public/authoritative evidence |
|---|---|
| `screened_feasible` | A current identifiable unit/listing; property type and intended commercial-school/tuition path reviewed against S012/S013; URA SPACE checked where applicable; no observed mandatory public blocker; every missing owner/URA/SCDF confirmation named. Public/agent claims are retained only as claims. |
| `verified_eligible` | All `screened_feasible` evidence **plus** current unit-specific authoritative passes for every applicable mandatory premises requirement: documentary owner/landlord consent; approved use, URA lodgment acknowledgment or planning decision as applicable; QP determination and SCDF approval/exemption/FSC evidence as applicable; no unresolved contradictory premises evidence. This does not certify school/operator registration or ordinary commercial/lease diligence. |

An unavailable check is not a pass. A confirmed mandatory failure is `ineligible`; insufficient or contradictory evidence is `unresolved`.

## Core release and optional extensions

The core release includes national planning-area screening; reproducible commercial nodes; preferred 2025 single-age population with the documented grouped-age fallback only if preflight fails; OneMap transit/walk accessibility if preflight passes, otherwise the honest proximity proxy; nationwide competitor discovery with coverage limits; complete manual validation of branches affecting shortlisted catchments; transparent financial scenarios and inverse break-even outputs; four-dimensional Pareto/five-profile sensitivity; an analytical report; and a static dashboard. Do not downgrade to the 2020 population fallback or proximity proxy unless the corresponding preflight actually fails.

Current-unit recommendations, exhaustive national manual branch validation, Monte Carlo, expansion cannibalisation, cluster-effect modelling and node-specific rent integration pending licensed evidence are optional later extensions.
